# Security policy

AckiVault is an experimental local AVM demonstration. It is not audited or
approved for real funds, and it has no supported Shellnet or Mainnet deployment.
Security fixes target the current `main` branch; there are no maintained releases.

## Report a vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/anvilfilbert/ackivault/security/advisories/new).
Include the affected commit, the steps to reproduce with test identities, the
expected and observed behavior, and any relevant sanitized receipts.

Do not publish exploit details in a public issue before review. Never include
private keys, seed phrases, access tokens, personal paths or real wallet data.
Non-sensitive bugs and documentation problems can be reported in GitHub issues.
